# Strategy Hub Architecture & Navigation Plan

This document defines the strategy-first hierarchical structure for the `ai-trade` Strategy Studio.

---

## Navigation & Workflow Hierarchy

```
┌────────────────────────────────────────────────────────────────────────┐
  1. STRATEGY SELECTION
  [ Strategy 04 (Supply/Demand) ] [ Strategy 01 (Alligator) ] [ Strategy 02 ] [ Strategy 03 ]
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
┌───────────────────────────────────▼────────────────────────────────────┐
  2. VERSION SELECTION
  [ Version 1.0 ]  [ Version 1.1 ]  [ Version 2.0 (Planned) ]  [ Version 3.0 (Planned) ]
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
┌───────────────────────────────────▼────────────────────────────────────┐
  3. SECTION NAVIGATION
  ┌───────────────────┬───────────────────┬───────────────────┬──────────┴────────┐
  │ 📜 Rules & Spec   │ 📊 Asset Backtests│ 📈 Interactive    │ 🖼️ Stored Visual  │
  │ (strategy.md)     │ (SPY, QQQ, Gold)  │    Charts Engine  │    Graph Gallery  │
  └───────────────────┴───────────────────┴───────────────────┴───────────────────┘
```

### 1. Strategy & Version Picker
- **Strategy 04**: Supply & Demand indicator strategy. Versions: `v1`, `v1.1`, `v2`, `v3`.
- **Strategy 01**: Bill Williams Alligator + Heikin Ashi strategy. Versions: `v1`, `v2`, `v3` (4H confirmation / 1H entry), `v4` (multi-tf cache).
- **Strategy 02**: Intraday EMA/ATR momentum strategy. Versions: `v1.3`, `v1.4`, `v1.5`.
- **Strategy 03**: Intraday ATR volatility reset strategy.

### 2. Strategy Specification & Rules Section
- Renders `strategy.md` and indicator specification documents (`indicator_spec_v0_1.md`, etc.).
- Displays entry trigger rules, stop-loss rules, take-profit multipliers, and RRMS risk scaling policies.

### 3. Asset Backtest Performance Results
- Multi-asset tab switcher: `SPY`, `QQQ`, `DIA`, `MGC (Micro Gold Futures)`, `VIX`.
- Displays summary KPI cards (Net PnL, Win Rate %, Profit Factor, Max Drawdown, Avg R) and complete trade log table.

### 4. Interactive Candlestick Charts & Stored Visual Graphs Gallery
- Interactive TradingView chart with indicator overlays and trade markers.
- Stored SVG visual review gallery generated by `render_strategy_04_trade_review`, `render_strategy_04_zone_review`, and long loss diagnostics.
